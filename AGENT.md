# AGENTS.md

## Stack
- React
- TypeScript
- Vite
- Tailwind CSS
- Framer Motion
- React Router
- Supabase

## Code rules
- Use strict TypeScript
- Prefer reusable components
- Keep files small and focused
- Use mobile-first responsive design
- Avoid inline messy logic in pages
- Store travel content in typed data files

## UX rules
- Design must feel premium and polished
- Use smooth but tasteful animations
- Keep accessibility in mind
- Premium-locked destinations must be visually distinct
- Shuffle cards must animate for 8 seconds before reveal

## Validation
- Run build before finishing
- Fix TypeScript errors
- Ensure auth flow works
- Ensure protected routes work
- Ensure free users only access Intramuros
